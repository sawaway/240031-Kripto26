# Vigenere Cipher

Program ini merupakan implementasi Vigenere Cipher menggunakan bahasa C++. Program dibuat untuk melakukan proses enkripsi dan dekripsi teks menggunakan sebuah key sebagai kunci.

## Penjelasan Program

Vigenere Cipher merupakan metode enkripsi yang menggunakan key untuk menentukan pergeseran setiap huruf pada plaintext. Key akan digunakan secara berulang apabila panjang teks lebih besar daripada panjang key.

Program ini memiliki tiga pilihan menu:

1. Enkripsi
   Digunakan untuk mengubah plaintext menjadi ciphertext berdasarkan key yang dimasukkan.

2. Dekripsi
   Digunakan untuk mengembalikan ciphertext menjadi plaintext menggunakan key yang sama.

3. Keluar
   Digunakan untuk mengakhiri program.

## Alur Program

1. Program menampilkan menu utama Vigenere Cipher.
2. Pengguna memilih menu enkripsi, dekripsi, atau keluar.
3. Jika memilih enkripsi atau dekripsi, pengguna diminta memasukkan teks dan key.
4. Program memeriksa key yang dimasukkan.
5. Program melakukan proses enkripsi atau dekripsi menggunakan key.
6. Hasil proses ditampilkan pada layar.
7. Setelah selesai, program kembali ke menu utama.
8. Program akan terus berjalan sampai pengguna memilih 3. Keluar.

## Fitur

* Enkripsi menggunakan Vigenere Cipher.
* Dekripsi menggunakan Vigenere Cipher.
* Key dapat digunakan berulang sesuai panjang teks.
* Huruf besar dan huruf kecil tetap dipertahankan.
* Spasi dan karakter selain huruf tidak diubah.
* Terdapat menu untuk mengulang proses tanpa menjalankan program kembali.
